# 🎬 Türk Dizi Karakteri Tahmin Oyunu

Türk dizilerindeki karakterleri tahmin etmeye dayalı, **Loldle** tarzında geliştirilmiş eğlenceli bir web oyunudur.

Oyuncular, verilen ipuçlarını kullanarak hangi Türk dizi karakterinin arandığını bulmaya çalışır. Her tahminde karakter hakkında farklı bilgiler ve ipuçları gösterilir.

## 🎮 Özellikler

* 🇹🇷 Türk dizilerinden karakterler
* 🔍 Karakter tahmin sistemi
* 💡 Tahminlere göre ipuçları
* 🎯 Doğru karakteri bulmaya dayalı oyun yapısı
* 📱 Mobil uyumlu tasarım
* 💻 Web ve masaüstü cihazlarla uyumlu arayüz
* 🔄 Yeni karakterler ve diziler eklenebilir yapı

## 🕹️ Nasıl Oynanır?

1. Oyuna gir.
2. Tahmin etmek istediğin karakteri seç veya yaz.
3. Verilen ipuçlarını incele.
4. İpuçlarından yararlanarak doğru karakteri bulmaya çalış.
5. Doğru tahmini yap ve oyunu tamamla! 🎉

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript

## 📌 Proje Hakkında

Bu proje, **web geliştirme, JavaScript ve interaktif oyun mekanikleri** üzerine pratik yapmak amacıyla geliştirilmiştir.

Projenin amacı, kullanıcıların Türk dizilerindeki karakterleri eğlenceli ve rekabetçi bir şekilde tahmin edebileceği basit ve kullanışlı bir oyun deneyimi sunmaktır.
